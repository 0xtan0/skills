      How to give feedback

      1. Set a status on a finding: "Post as is" (post the suggestion), "Ignore", "Validate first" (Claude checks it against the code before it is posted) or "Question". The page saves it immediately.
      2. Write a comment or a question in the box. The page saves it when you stop typing.
      3. Turn on "Request re-review" to ask Claude to check the finding again.
      4. Use the box at the top of each PR for a comment on the full PR.
      5. To chat about one finding, write in "Ask Claude" and press "Send to Claude". Claude answers in a comment thread on that card. The chat does not change your saved status or comment.
      6. Tell Claude in the session to read the feedback. Claude writes a reply, and the reply shows under the finding.
      Each finding keeps the id, severity, file and line of the review. The text is in Simplified Technical English. Open "Original reviewer wording" to see the source text.
