Production: AWS accounts, regions and repos

Key safety points

  • Signing keys stay in AWS KMS. Only the signature leaves KMS.
  • The keys are in a separate security account. The keeper account cannot export or change them.
  • The paymaster pays the gas. It checks each request again before it sends. One keeper also holds funds to pay the Hyperlane cross-chain fee.
  • Staging only simulates. It sends the actions to Slack for review. It does not send transactions.
